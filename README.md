Stock Trading Platform — A Java console-based stock trading application that allows users to view market prices, buy and sell stocks, manage their portfolio, and track transaction history. Built using Java, OOP, HashMap, ArrayList, and Scanner.
Features:-
📊 View available stocks and their prices
💰 Buy stocks
📉 Sell stocks
💼 View portfolio and total portfolio value
📜 View transaction history
💵 Manage account balance
❌ Validate insufficient balance and shares
